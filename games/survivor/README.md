# survivor

A top-down co-op survival game on `unified`, its example of a game at scale: up to four players against waves of
enemies, crates and barrels, gems and level-ups. A Godot project (this folder is `res://`): the sim, its tests, the
headless binary and the GDExtension in `simulation/` (Odin), everything Godot in `game/`. Spec:
[`SPEC.md`](SPEC.md). `uni run survivor` plays it.

## Controls

WASD / arrows / left stick to move, Space / pad A to dash, 1 2 3 / pad X Y B to pick a level-up, Esc / Start for
the menu, F1 for the dev UI.
